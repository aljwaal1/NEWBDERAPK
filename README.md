# عالم بدر - النسخة المبهرة Native APK

هذه نسخة جديدة بالكامل من تطبيق بدر، Flutter Native Android فقط، وليست WebView.

## الموجود

- تصميم عربي RTL مخصص للأطفال.
- شاشة رئيسية مبهرة بأسلوب خريطة عوالم.
- عوالم تعليمية: الحيوانات، الطعام، المركبات، الحروف، الأرقام، الألوان والأشكال.
- نطق عربي وإنجليزي عبر Flutter TTS.
- تسجيل صوت عربي حقيقي Native عبر Kotlin + MethodChannel.
- حفظ تسجيلات الطفل/الأهل داخل الجهاز وتشغيلها بدل صوت الجهاز.
- ألعاب تعليمية واضحة: اختر الصورة، اسمع واختر، العد، الذاكرة.
- قصص بدر قصيرة ومنظمة.
- صفحة تقدم: نجوم، كلمات متعلمة، تسجيلات، ألعاب.
- GitHub Actions يبني APK مباشر في `apk/badr.apk`.
